CSS Layouts

El CSS Layout es el conjunto de técnicas que permite estructurar, posicionar y distribuir los elementos de una página web (como menús, textos e imágenes) para que la interfaz se vea organizada y se adapte a cualquier tamaño de pantalla. Sus herramientas principales son Flexbox para maquetar en una dimensión (filas o columnas), Grid para dos dimensiones (filas y columnas simultáneas), la propiedad position para ubicar elementos en coordenadas específicas y la propiedad display para definir el comportamiento básico de las cajas.

Animaciones

Las animaciones en CSS permiten transicionar suavemente entre diferentes estilos de un elemento web (como cambiar su color, moverlo de lugar, rotarlo o cambiar su tamaño) a lo largo del tiempo, sin necesidad de utilizar JavaScript.

Sass

Sass es un lenguaje de estilo basado en CSS que nos permite usar variables, anidamiento, mixins y otras características que hacen que el código CSS sea más mantenible y reutilizable.

Te presentamos las preguntas más comunes sobre el curso.

¿Qué es CSS?

CSS (por sus siglas en inglés, Cascading Style Sheets, o Hojas de Estilo en Cascada) es el lenguaje de programación de diseño que se utiliza para dar formato, color, diseño y adaptabilidad a las páginas web escritas en HTML.

¿Qué aprenderé en este curso?

En este curso aprenderás a crear diseños modernos y responsivos utilizando CSS GRID. Aprenderás a estructurar tu contenido de manera eficiente y a crear layouts complejos con solo unas pocas líneas de código.

¿Qué es CSS GRID?

CSS GRID es un sistema de diseño bidimensional que te permite crear layouts complejos y responsivos con facilidad. Con CSS GRID, puedes definir filas y columnas para organizar tu contenido de manera más eficiente.
